Noto Emoji (monochrome), from https://github.com/googlefonts/noto-emoji,
release 20260921 as packaged by Fedora 44 (google-noto-emoji-fonts).
SIL Open Font License 1.1, see OFL.txt.

Bundled as a fallback so a subject or body with an emoji never draws the
missing-glyph box on a system without an emoji font. Space Grotesk has no
emoji; a system colour emoji font, when installed, can still win the
fallback.
